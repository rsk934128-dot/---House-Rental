# 📱 বাসা বাড়ি ভাড়া - Android APK Build & GitHub Actions Release

এই রিপোজিটরিতে **বাসা বাড়ি ভাড়া** অ্যাপের জন্য স্বয়ংক্রিয় GitHub Actions সিআই/সিডি (CI/CD) পাইপলাইন সেটআপ করা আছে, যা সরাসরি GitHub থেকে অ্যান্ড্রয়েড APK (`BashaBariVara.apk`) কম্পাইল ও রিলিজ করে।

---

## 🚀 গিটহাব থেকে সরাসরি APK রিলিজ করার নিয়ম

### পদ্ধতি ১: ভার্সন ট্যাগ দিয়ে অটোমেটিক রিলিজ (Recommended)
টার্মিনালে নিচের কমান্ডগুলো রান করুন:

```bash
git add .
git commit -m "Release v1.0.0 Android APK"
git tag v1.0.0
git push origin main --tags
```

গিটহাবে ট্যাগ পুশ করার সাথে সাথে GitHub Actions স্বয়ংক্রিয়ভাবে:
1. Ubuntu সার্ভারে Node.js 22 (LTS) এবং Java JDK 17 সেটআপ করবে।
2. Vite দিয়ে ওয়েব বিল্ড (`npm run build`) সম্পন্ন করবে।
3. Capacitor এর মাধ্যমে অ্যান্ড্রয়েড প্রজেক্ট সিঙ্ক করবে।
4. `./gradlew assembleDebug` রান করে **`BashaBariVara.apk`** তৈরি করবে।
5. আপনার GitHub রিপোজিটরির **Releases** সেকশনে সরাসরি ডাউনলোডযোগ্য APK ফাইল হিসেবে প্রকাশ করবে!

---

### পদ্ধতি ২: GitHub ব্রাউজার থেকে ১-ক্লিকে ম্যানুয়াল বিল্ড
1. আপনার GitHub রিপোজিটরির **Actions** ট্যাবে ক্লিক করুন।
2. বামপাশের মেনু থেকে **"Build & Release Android APK"** সিলেক্ট করুন।
3. ডানপাশে থাকা **"Run workflow"** বাটনে ক্লিক করুন।
4. মাত্র ২-৩ মিনিটের মধ্যে আপনার সম্পূর্ণ নতুন APK ফাইল তৈরি হয়ে যাবে।

---

## 📲 অ্যান্ড্রয়েড ফোনে APK ইনস্টল করার নিয়ম

1. GitHub Releases পেজ থেকে **`BashaBariVara.apk`** ডাউনলোড করুন।
2. ফোনের **Downloads** ফোল্ডার থেকে ফাইলটি খুলুন।
3. যদি ফোন *'Install unknown apps'* বার্তা দেখায়, তবে **Settings**-এ গিয়ে **'Allow from this source'** অন করে দিন।
4. **Install** বাটনে চাপ দিন — অ্যাপটি ফোনের হোমস্ক্রিনে চলে আসবে!

---

## 🌐 ব্রাউজার থেকে সরাসরি PWA হিসেবে ব্যবহার (কোনো ডাউনলোড ছাড়া)
Android ও iOS উভয় ফোনেই Google Chrome বা Safari ব্রাউজারে সাইটটি ওপেন করে **"Add to Home Screen"** চাপলে যেকোনো ডাউনলোড ছাড়াই সরাসরি দেশীয় অ্যাপের মতো ব্যবহার করা যায়।
